Coding Contest

Showcase your programming skills in an intense coding battle. Solve challenges in C, Java, and Python against the clock!

Event Description

The Coding Contest is an ultimate test of logical thinking and problem-solving skills. Participants will be given a series of programming challenges to solve within a limited time.

Event Guidelines

  • Participants can code in C, Java, or Python.
  • The contest will be conducted in two rounds: Preliminary & Final.
  • Teams can have 2 to 4 members.
  • Use of external resources is strictly prohibited.
  • Plagiarism will lead to immediate disqualification.
  • Decisions by the judges will be final.

Event Timings

Preliminary Round: 10:00 AM - 11:30 AM

Final Round: 2:00 PM - 3:30 PM

Event Venue

Location: Computer Science Lab, Block A, TechFest Campus
